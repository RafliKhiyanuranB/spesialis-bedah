Evaluasi Website Spesialis Bedah

No Kriteria Evaluasi Keterangan Status
1 Kelengkapan Section
  • Header: Logo dan judul website
  • Navigation: Menu navigasi utama
  • Main Content: Konten utama website
  • Sidebarr content: Konten Tambahan website
  • Footer: Informasi kontak dan copyright
2 Kelengkapan Jumlah Halaman
  • index.html (Beranda)
  • form.html (Form Pendaftaran)
  • evaluation.html (Evaluasi)
  • about.html (Tentang Kami)
3 Kesesuaian Nama File Homepage File utama menggunakan nama index.html sesuai standar
4 Kelengkapan Elemen HTML Form
  • Textbox: Nama, NIK, Email, Telepon
  • Dropdown: Golongan Darah
  • Checkbox: Riwayat Penyakit
  • Radio Button: Jenis Kelamin
  • Textarea: Gejala/Keluhan
  • Submit Button: Kirim Formulir
5 Kelengkapan Penerapan Validasi Form
  • Validasi Masukan Wajib
  • Validasi Format Numerik (NIK, Telepon)
  • Validasi Format Alfabet (Nama)
  • Validasi Format Email
  • Validasi Panjang Karakter
  • Validasi Tanggal (Lahir & Konsultasi)
6 Kesesuaian Pesan Error Validasi
  • Pesan error ditampilkan di bawah field terkait
  • Pesan error informatif dan mudah dipahami
  • Validasi real-time saat input
7 Konsistensi Desain Antar Halaman
  • Header dan Footer konsisten di semua halaman
  • Warna dan font seragam
  • Layout responsif di semua halaman
8 Kesesuaian Website Terhadap Tema
  • Konten sesuai tema spesialis bedah
  • Form pendaftaran pasien yang relevan
  • Informasi medis yang akurat
